# Endpoint Detection (Windows telemetry)

Detections written from public recordings of real attack techniques on Windows: Sysmon and Windows Event Log data
loaded into ClickHouse, analysed, and turned into Sigma rules that are validated against both the attack data and data
where they must stay silent.

> Work in progress. The index and totals are generated by `scripts/update-readme.py` (Phase 5).

The procedure per technique is in [docs/workflow.md](docs/workflow.md); every write-up follows [TEMPLATE.md](TEMPLATE.md).

## Safety

Every dataset is a recording made in someone else's lab. Nothing is executed here, no Windows host is involved, and no
attack tool is downloaded or run. Datasets stay on the data disk and never enter this repository.
